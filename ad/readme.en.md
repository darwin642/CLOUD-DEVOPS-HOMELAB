# 🪟 Active Directory Lab

A practical **Active Directory** environment built on Windows Server.

The lab covers basic Active Directory administration, user and computer management, DNS, DHCP, and Group Policy.

## 🏗️ Hybrid Integration

The Active Directory environment has been integrated with Azure using **Azure AD Connect**. User identities are synchronized between Active Directory and Azure.

**Tailscale** is used to provide network communication between the Azure and Active Directory environments.
