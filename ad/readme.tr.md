🪟 Active Directory Lab

Windows Server üzerinde oluşturulmuş uygulamalı bir Active Directory ortamıdır.

Laboratuvar; temel Active Directory yönetimi, kullanıcı ve bilgisayar yönetimi, DNS, DHCP ve Group Policy yapılandırmalarını kapsamaktadır.

🏗️ Hybrid Integration

Active Directory ortamı Azure AD Connect kullanılarak Azure ile hibritlenmiştir. Kullanıcı kimlikleri Active Directory ile Azure arasında senkronize edilmektedir.

İki ortam arasındaki ağ iletişimi ise Tailscale üzerinden sağlanarak Azure ve Active Directory kaynaklarının birbirleriyle iletişim kurması sağlanmıştır.
