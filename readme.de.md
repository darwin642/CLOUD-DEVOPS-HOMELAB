# ☁️ Cloud & DevOps Lab Portfolio

Ein praxisorientiertes Portfolio, das meinen Weg vom IT Support zu Cloud Infrastructure und DevOps dokumentiert.

Dieses Portfolio konzentriert sich nicht nur auf theoretisches Lernen, sondern auf den Aufbau, die Konfiguration, die Fehlerbehebung und die Automatisierung realer Infrastruktur.

---

## ☁️ Cloud-Plattformen

### Microsoft Azure

Praxisorientiertes Azure-Infrastrukturlabor mit folgenden Themen:

* Azure Virtual Networks
* Subnetze
* Network Security Groups
* Virtual Machines
* Routing
* Private Endpoints
* Managed Identities
* Azure Storage
* Azure CLI
* Windows Server

[Azure Lab anzeigen →](azure-lab/)

---

### Amazon Web Services

Praxisorientiertes AWS-Infrastrukturlabor mit folgenden Themen:

* VPC
* Öffentliche und private Subnetze
* Internet Gateway
* Route Tables
* EC2
* Application Load Balancer
* Security Groups
* IAM
* Systems Manager
* VPC Endpoints
* CloudWatch
* SNS
* S3
* Multi-AZ-Architektur

Die Infrastruktur wird mit Terraform verwaltet.

[AWS Lab anzeigen →](aws-terraform-lab/)
